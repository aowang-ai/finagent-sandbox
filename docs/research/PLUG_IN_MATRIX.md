# Plug-in matrix

> Superseded: scoring is parallel scorecard (see GOAL.md). FINSABER is not a global kernel.

How each studied system attaches an agent, and how that feeds **this** repo’s `AcceptanceReport` (`ACCEPTANCE_REPORT.schema.json`). Cost is an estimate (`S` days / `M` 1–2 weeks / `L` 3–6 weeks / `XL` wrong layer). Citations: fetched URL or `path:symbol`.

**Harness type:** `runtime` = turn executor; `eval` = exam runner; `both` = product has both, different SPIs.

## Parallel scorecard (no suite veto)

`admission.decision` is **completeness** of the scorecard (`adapters/base.py:evaluate_admission`), not a FINSABER-kernel veto. A FINSABER fail does not hide AMA / StockBench / FinTool / DeepFund rows. ClawBench scores and Hermes `completed=true` trajectories are still not suite_ids.
